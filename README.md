# Pleamar Property Management

Sitio web bilingüe (ES/EN) para una empresa de administración de villas de lujo en Guanacaste, Costa Rica.

El proyecto es una página estática construida con HTML, CSS y JavaScript, sin dependencias ni proceso de compilación.

## Ver el sitio localmente

Puedes abrir `index.html` directamente en el navegador. Para probarlo mediante un servidor local:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Estructura

- `index.html`: contenido, estilos y comportamiento del sitio.
- `img/`: fotografías optimizadas en formato WebP.
- `PRODUCT.md`: objetivo, audiencia y principios del producto.
- `DESIGN.md`: sistema visual y reglas de diseño.
- `CONTRIBUTING.md`: flujo recomendado para proponer cambios.

## Colaborar

Las aportaciones se realizan mediante ramas y pull requests. Antes de modificar la interfaz, revisa `PRODUCT.md` y `DESIGN.md` para conservar el posicionamiento y la identidad visual.

Consulta [CONTRIBUTING.md](CONTRIBUTING.md) para ver el proceso completo.

## Publicación

El sitio es compatible con GitHub Pages y puede publicarse directamente desde la raíz de la rama `main`.
